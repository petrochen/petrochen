# Alex Petrochenko

**Embedded & IoT · Reverse Engineering · Practical Tools · Browser Games**

I build practical tools for hardware, infrastructure, and the web — with a focus on reverse engineering and making devices useful for longer.

Based in Lisbon, Portugal.

## Hardware & reverse engineering

- **[ESP8266 Weather Clock](https://github.com/petrochen/esp8266-weather-clock-opensource)** — open-source firmware for DIY weather clocks, reverse-engineered from a consumer kit.
- **[iCharger Python](https://github.com/petrochen/icharger-python)** — USB control and measurement automation for Junsi iCharger battery chargers.
- **[ISDT Firmware Flasher](https://github.com/petrochen/isdt-firmware-flasher)** — tools for flashing ISDT charger firmware without Windows.

## Software & infrastructure

- **[Audio Input Priority](https://github.com/petrochen/audio-input-priority)** — control which microphone macOS uses when audio devices connect.
- **[Guit95](https://github.com/petrochen/guit95)** — a modern revival of a classic guitar learning application.
- **[Xray Double Hop](https://github.com/petrochen/xray-double-hop)** — configuration and tooling for a two-hop Xray connection.

## Vibe-coded arcade

A series of retro browser games built with AI-assisted coding. Play directly in your browser, on desktop or mobile.

| Game | Play | Source |
| --- | --- | --- |
| **Tetris** | [Play Tetris](https://tetris.petrochenko.info) | [Code](https://github.com/petrochen/tetris) |
| **Pac-Man** | [Play Pac-Man](https://pacman.petrochenko.info) | [Code](https://github.com/petrochen/pacman) |
| **Space Invaders** | [Play Space Invaders](https://invaders.petrochenko.info) | [Code](https://github.com/petrochen/space-invaders) |
| **Arkanoid** | [Play Arkanoid](https://arkanoid.petrochenko.info) | [Code](https://github.com/petrochen/arkanoid) |

Each game runs from a single HTML file, with no dependencies or build step. The collection also has an [arcade leaderboard API](https://github.com/petrochen/arcade-api) built on Cloudflare Workers and D1.

More game projects: [TrimAscension](https://github.com/petrochen/TrimAscension), a Minecraft armor-trim mod; [Azul Score](https://github.com/petrochen/azul-score), a board-game scoring companion; and [Pirate Paper Randomizer](https://github.com/petrochen/pirate-paper-randomizer), a coordinate caller for a paper treasure-hunt game.
